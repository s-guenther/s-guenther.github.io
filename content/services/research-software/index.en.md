Many technical questions are answered with spreadsheets, scripts or one-off
calculations that are hard to trace, extend or apply to new cases later. I
turn them into tools that make exactly this possible.

- Turning existing Excel or Matlab calculations into Python tools.
- Implementing models and algorithms from the literature or from your own
  development.
- Version control, documentation and tests, so the software can be
  maintained and handed over.

**Tools:** Python (NumPy, Pyomo), Matlab/Simulink, Git, Linux.

Examples: [storage sizing for wind farms]({{< ref "projects/wind-farm" >}}),
open-source software on hybrid energy storage (see
[About]({{< ref "about" >}})).
