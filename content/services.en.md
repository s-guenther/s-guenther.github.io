## Typical tasks

### Sizing and assessing energy storage

Which storage size and operating strategy suit a given load or generation
profile? Is a storage system worthwhile, and is a combination of two storage
technologies worthwhile? I formulate optimisation problems (linear and
nonlinear) and simulate operating strategies across many profiles and
variants.

### Assessing flexibility potential

How much load can be shifted in time, and what is it worth? I developed an
assessment tool for this question and ran analyses with it (see
[projects]({{< ref "projects" >}})).

### Analysing measurement and time-series data

Cleaning and statistically analysing load, operating and measurement data, and
presenting the results so that decisions can rest on them.

### Automating calculations

Turning existing Excel or Matlab calculations into traceable, reusable Python
tools. Parameter studies with many variants, on a computing cluster if needed.

## How it works

1. A short, non-binding conversation about the question.
2. An offer stating scope, deliverables and effort.
3. The work itself, with interim results.
4. Handover: report, source code and documentation, so that the results can
   be traced and reproduced.
